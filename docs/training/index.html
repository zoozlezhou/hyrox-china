8 个标准训练站点

滑雪机 SkiErg

模拟越野滑雪，考验上肢耐力和核心稳定性。

💡 技巧要点

  • ✓ 保持稳定的节奏
  • ✓ 利用体重下压
  • ✓ 核心收紧，不要过度后仰

🎯 目标肌群

背阔肌肱二头肌核心
🛷 站点 2 50m (4次×12.5m)

推雪橇 Heavy Sled Push

推动 152kg（男）/ 102kg（女）雪橇，考验腿部爆发力。

💡 技巧要点

  • ✓ 低重心，手臂伸直
  • ✓ 小步快频
  • ✓ 腿部发力为主

🎯 目标肌群

股四头肌臀大肌小腿
🏋️ 站点 3 50m (4次×12.5m)

拉雪橇 Sled Pull

用绳索拉动 76kg（男）/ 51kg（女）雪橇，考验上肢拉力。

💡 技巧要点

  • ✓ 交替拉绳，不要同时用双手
  • ✓ 脚踩绳索时稳住
  • ✓ 核心保持紧张

🎯 目标肌群

背阔肌肱二头肌前臂
💪 站点 4 80m (8次×10m)

波比跳远 Burpee Broad Jump

做波比跳后向前跳跃 10 米，全身爆发力考验。

💡 技巧要点

  • ✓ 波比跳要标准：胸触地
  • ✓ 跳跃尽量远
  • ✓ 落地缓冲，保护膝盖

🎯 目标肌群

全身胸肌股四头肌
🚣 站点 5 1000m

划船机 Rowing

室内划船机，考验心肺耐力和全身协调。

💡 技巧要点

  • ✓ 60% 腿部、30% 核心、10% 手臂
  • ✓ 保持稳定的桨频
  • ✓ 不要过度后仰

🎯 目标肌群

背阔肌股四头肌核心
🏃 站点 6 200m (4次×50m)

农夫行走 Farmers Carry

双手各提 32kg（男）/ 24kg（女）壶铃行走。

💡 技巧要点

  • ✓ 挺胸收腹，不要驼背
  • ✓ 小步快频
  • ✓ 握力是关键瓶颈

🎯 目标肌群

前臂斜方肌核心
🦵 站点 7 100m

沙袋弓步 Lunges

肩扛 20kg（男）/ 10kg（女）沙袋做弓步走。

💡 技巧要点

  • ✓ 后膝接近地面
  • ✓ 上身保持直立
  • ✓ 步幅不要太大

🎯 目标肌群

股四头肌臀大肌核心
⚾ 站点 8 75次

墙球 Wall Balls

将 6kg（男）/ 4kg（女）球抛至 3.05m（男）/ 2.72m（女）目标。

💡 技巧要点

  • ✓ 深蹲发力，不要只用手臂
  • ✓ 球到最高点时接住
  • ✓ 保持节奏，不要前快后慢
